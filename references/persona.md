# 人物档案规范

## 输入

优先使用清晰、无遮挡、五官可辨认的人物图。现成人物 IP 图直接作为身份来源，不重新设计。真人照片只用于提取可观察特征，不推断姓名、职业、民族、健康、政治、宗教或其他敏感属性。

## 固定信息

人物档案记录：

- 名称与封面作者名；
- 干净人物参考图；
- 卡片动作；
- 主题色；
- 可选账号；
- `draft` 或 `confirmed` 状态。

人物确认后，文章变化不得改变人物身份。允许改变姿态、手势、视线和轻微表情；保持脸型、五官比例、发型、体型、服装、鞋子与配件一致。

## 主题色

用户指定 Hex 色时优先使用。没有指定时，从服装或稳定配件选择一个非肤色、非黑白灰候选色，并随人物样稿一起确认。每个人物只使用一个主强调色，封面与内页从该颜色派生深色和浅色。

## 确认门

草稿人物不得用于正式文章。展示人物参考、名称、动作和主题色后，只询问确认或修改。只有用户明确表示确认时才更新状态。
