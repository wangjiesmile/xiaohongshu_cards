# 人物资产生成规范

## 输入检查

人物照片应清晰、无遮挡、五官可辨认。多人照片先确认目标人物。现成人物 IP 图作为既有设计使用，不重新设计身份。

只记录可观察信息：脸型、五官比例、发型、体型、服装、鞋子、配件和稳定颜色。不得推断姓名、年龄、职业、民族、健康、政治、宗教或其他敏感属性。

## 首次人物资产

生成三项结果：

1. `character-sheet.png`：同一人物的正面、四分之三侧面、侧面和背面视图，身份、服装与比例一致；
2. `character-reference-clean.png`：透明或干净浅色背景上的完整人物，不裁头、不裁脚；
3. `character-spec.md`：用文字记录稳定外观、服装、配件、比例、允许变化和禁止变化。

设定板只用于身份确认，不直接作为卡片插图。人物图不得包含用户姓名、账号、文章标题、Logo 或水印。

## 卡片动作图

人物确认后，根据用户选择生成 `character-card-pose.png`。可以改变动作、手势、朝向、视线和轻微表情；保持脸、发型、体型、服装、鞋子和配件。

动作应服务内容，例如站立讲解、指向内容、拿平板、白板书写或坐姿操作。让人物视线或手势朝向主要内容区，但不改变用户指定动作的核心含义。

## 生成提示结构

提示词按以下顺序组织：

```text
任务类型 + 身份参考约束 + 稳定外观与服装 + 指定动作 + 构图与背景 + 禁止变化 + 输出尺寸
```

每次只修正一个主要问题。身份漂移时先修正脸、发型和比例；动作不清楚时再修正手势与物件；不要同时重做全部视觉信息。

没有图像生成能力时，输出完整提示词、参考图绝对路径、目标文件名和保存目录，并明确标记人物资产尚未完成，不能确认人物。
